## The Core Problem We Solved

**Root cause of 0% success rate:**
- Training data: wrist position in **MediaPipe world frame** (values ~0.03m, centred near zero)
- Eval: Franka EEF in **Isaac Sim world frame** (values ~0.5–1.3m)
- Scale mismatch ~100×, axes also permuted
- Confirmed by testing with `--arm_scale 100` → arm reached the cube

**Gripper issue:**
- Raw `norm(thumb_tip - index_tip)` is too noisy → Franka gripper opens/closes erratically
- Fix: EMA smoothing (α=0.10) + hysteresis dead zone (close <2cm, open >4cm)

## Coordinate Frames (critical knowledge)

```
Isaac Sim world frame:  x = forward (+),  y = left (+),  z = up (+)
Franka EEF local frame: x = up,           y = right,     z = forward
MediaPipe world frame:  x = left-right,   y = forward-back, z = height (often inverted)
```

**For eval:** IK controller takes commands in **Isaac Sim world frame**.
The EEF local frame doesn't matter — IK handles that internally.

**For recording:** `wrist_robot` in `landmarks.json` is now saved in
**Isaac Sim world frame** after camera calibration transform.

### Step 1: Calibrate camera once
```bash
python record_demos.py
# Press C → follow 3-point calibration prompts → saves demos/calib.json
```

**3 reference positions** (place wrist here during calibration):
| Ref | World position (metres) | Description |
|-----|-------------------------|-------------|
| 1   | (0.45, -0.15, 0.90)    | Above cube start position |
| 2   | (0.60,  0.10, 0.90)    | Above box centre |
| 3   | (0.45, -0.15, 1.10)    | 20 cm straight up from Ref 1 |

The transform is saved to `demos/calib.json` and auto-loaded next run.

### Step 2: Record demos
- SPACE = start/stop, Q = quit
- Console shows `grip:open(0.035)` and `world:(0.45, -0.15, 0.90)` overlaid

### Step 3: Convert to LeRobot
```bash
python convert_to_lerobot.py \
  --demos-dir /workspace/demos \
  --output-dir /workspace/lerobot_dataset \
  --task "pick up the cube and place it inside the cardboard box"
```

Generates `meta/modality.json` automatically with correct key mapping.

Same docker command as v3 (see GROOT_CONTEXT.md), but now with correctly calibrated data.

## Isaac Sim Eval Setup

### Containers
| Container | Purpose |
|-----------|---------|
| `gr00t:latest` | GR00T policy server (runs on GPU) |
| `isaac-lab-base-gui` | Isaac Sim eval environment |

Both use `--network host` → they share localhost, ZMQ port 5555.

### Start policy server
```bash
docker run --rm --gpus all --ipc=host --network host \
  -e HF_TOKEN=<your_token> \
  -v /root/Isaac-GR00T/checkpoints/groot_pick_place_v3:/checkpoints \
  -v /root/Isaac-GR00T/modality_human_hand.py:/workspace/modality_human_hand.py \
  gr00t:latest \
  python /workspace/gr00t/eval/run_gr00t_server.py \
    --model-path /checkpoints \
    --embodiment-tag new_embodiment \
    --modality-config-path /workspace/modality_human_hand.py \
    --port 5555
```

### Start eval (inside isaac-lab-base-gui)
```bash
# Restart container if killed:
cd /root/groot && bash docker/container.sh start

docker exec -it isaac-lab-base-gui bash
/workspace/isaaclab/isaaclab.sh -p /workspace/isaaclab/scripts/eval_groot_franka.py \
  --headless --enable_cameras
  # or add --livestream 1 to watch in browser at http://<ip>:8211
```

### Scene layout
- White table with 4 legs, surface at z=0.75m
- Franka Panda base on table surface at (0, 0, 0.75)
- Cardboard box (30×20×20cm, brown) at (0.60, 0.10, 0.75)
- Cube (8×8×8cm, orange) at (0.45, -0.15, 0.79)
- Camera: 45° overhead, 1280×720, matches training view

### Eval script key notes
- `pyzmq` and `msgpack` must be installed in Isaac Sim's Python:
  ```bash
  docker exec isaac-lab-base-gui bash -c \
    "/workspace/isaaclab/_isaac_sim/python.sh -m pip install pyzmq msgpack"
  ```
- GR00T server uses ZMQ (not HTTP), msgpack with numpy `.npy` encoding
- Observation format: `video.top (1,1,H,W,3)`, `state.single_arm (1,1,3)`, `state.gripper (1,1,1)`
- Action format returned: `[{"single_arm": (1,H,3), "gripper": (1,H,1)}, {}]`
